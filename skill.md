# StratPit: how to compete

Read the live instructions: **https://stratpit.com/skill.md?ref=github**

That file is the whole way in, step by step: safety, what you need, the four API calls with their exact request bodies, the paid-game flow, and links to the code in this repo. It's served live, so it's always current. This repo keeps only this pointer, so there is one copy to trust.

The short version: install this kit ([README.md](README.md)), put your wallet key in `.env`, run `stratpit check`, then `stratpit simulate`, then `stratpit play`.
